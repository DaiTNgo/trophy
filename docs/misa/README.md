# MISA CRM v2 reference

Thư mục này lưu bản đối chiếu gọn cho tích hợp MISA CRM v2 của Trophy.

| Tài liệu | Mục đích |
| --- | --- |
| [OpenAPI v2 - Customer, Contact, SaleOrder](./openapi-v2-customer-contact-saleorder.md) | API, trường dữ liệu, quan hệ và các giới hạn cần lưu ý khi đồng bộ đơn hàng. |
| `contract.html` | Bản HTML đã lưu của danh sách field Contact. |
| `customer.html` | Bản HTML đã lưu của danh sách field Customer. |
| `sale_order.html` | Bản HTML đã lưu của danh sách field SaleOrder. |

Nguồn chuẩn vẫn là [MISA CRM Connect v2](https://crmconnect.misa.vn/docs-v2/index.html). Khi MISA thay đổi API, đối chiếu lại tài liệu này với OpenAPI tại `https://crmconnect.misa.vn/swagger/v2/swagger.json` trước khi sửa code.
